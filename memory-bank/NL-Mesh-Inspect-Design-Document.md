# 自然语言 Mesh 模型交互与检测平台 (NL-Mesh-Inspect) 设计文档

## 1. 项目概述

本平台旨在降低 3D 模型分析与质量检测的门槛。用户无需学习复杂的 CAD 软件或点击数百个菜单，只需通过自然语言指令（如："检测模型底部的厚度是否小于 2mm" 或 "选中所有直径大于 10cm 的孔洞"）即可完成模型交互、几何分析和拓扑检测。

## 2. 核心架构

系统分为四层结构：

### 前端展示层 (UI/UX)
基于 WebGL (Three.js/Babylon.js) 的 3D 渲染器，包含对话窗口。

### 语义解析层 (NLP Engine)
利用 LLM（如 GPT-4o 或 Claude 3.5）将模糊指令转化为结构化的 Mesh 操作指令 (MOL)。

### 逻辑执行层 (Execution Core)
封装核心几何算法（如计算法线、测量距离、拓扑修复）。

### 数据模型层 (Data Layer)
维护 Mesh 的半边结构 (Half-edge structure) 和空间索引（如 BVH）。

## 3. 功能模块设计

### 3.1 自然语言处理流程

**意图识别**：判断用户是在执行"查询"（测量）、"操作"（选中/着色）还是"修改"（修复）。

**实体提取**：识别几何特征（如：边、面、孔、法线）和数值约束（如：> 5.0, 红色）。

**代码生成**：LLM 生成 Python 脚本或 JSON DSL，调用底层的几何 API。

### 3.2 几何检测算法库

**壁厚检测 (Wall Thickness)**：基于射线碰撞检测计算相对面的距离。

**倒扣检测 (Undercut Analysis)**：根据预设的脱模方向检测模型死角。

**拓扑检查**：检测非流形 (Non-manifold) 边缘、自相交面和孤立顶点。

**特征识别**：自动识别圆柱面（孔洞）、平面和特定曲率区域。

### 3.3 交互逻辑

**高亮反馈**：根据指令动态更新特定面的颜色或发光效果。

**多轮对话**：支持基于上下文的追问，例如："选中那些薄弱点"、"给它们涂成红色"。

## 4. 技术栈建议

**3D 引擎**：Three.js (Web端) 或 PyVista (后端处理)。

**几何处理**：libigl 或 CGAL (C++)，或 Python 环境下的 Trimesh。

**LLM 框架**：LangChain 用于管理 Prompt 和 Tool Calling。

**空间加速**：three-mesh-bvh 以实现毫秒级的实时检测交互。

## 5. 典型用例 (User Stories)

**案例 A (工业质检)**：用户上传 STL 文件，输入"找出所有夹角小于 90 度的内边缘"，系统自动在 3D 视图中高亮这些边缘。

**案例 B (3D 打印准备)**：用户提问"这个模型可以不用支撑打印吗？"，系统计算悬垂角并给出热力图反馈。

## 6. 未来扩展

**语音交互**：集成 Web Speech API 实现实时语音指令。

**多模态增强**：支持用户点击模型的同时配合口令（如：点击一个面说"以此为基准测量高度"）。

**自动化修复**：从检测问题直接跳转到"一键修复"指令。
